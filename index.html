Efficient Frontier — Risk vs Return Tradeoff
The efficient frontier (Markowitz, 1952 — Nobel Prize 1990) shows the maximum return achievable for each level of risk. Portfolios above the frontier are unachievable; portfolios below are sub-optimal. The ★ tangency portfolio maximizes the Sharpe ratio.

Black-Litterman Model — Combine Market Equilibrium with Investor Views

The BL model starts with implied equilibrium returns (reverse-optimized from market weights) and blends them with your active views. This addresses MVO's sensitivity to input errors. View confidence: 0% = ignore view, 100% = absolute certainty.
